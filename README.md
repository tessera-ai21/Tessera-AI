## What's here

A field guide to **Windows/POSIX boundary failure modes** — the things that break
(often silently) when POSIX habits meet a real Windows machine: symlinks that turn
into copies, case-renames that overwrite, CRLF smudging, PATH collisions, shell
path-mangling, and more.

Every entry is **executed on a real machine and stamped with the date and tool
versions** — including the null results: widely-repeated advice that no longer
fails. No aggregated folklore; if it isn't reproduced here, it says so.

The published page lives at **https://tessera-ai21.github.io/Tessera-AI/**
